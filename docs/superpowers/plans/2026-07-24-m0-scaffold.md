# agi-playground M0 Scaffold Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship M0 of agi-playground: full repo scaffold, README manifesto, CI, published research, infra lane docs, and the public GitHub repo `kleon1024/agi-playground`.

**Architecture:** Docs+code monorepo per the approved design doc (`docs/superpowers/specs/2026-07-24-agi-playground-design.md`): 8 `tracks/`, a `speedrun/` flagship pipeline, `infra/` compute-lane docs, `research/` landscape publications. M0 is scaffold + docs + CI only — no model code beyond a structure-validating test suite.

**Tech Stack:** Python 3.12, uv, ruff, pytest, GitHub Actions.

## Global Constraints

- All published content in English (repo is open source, English-first).
- License: MIT. GitHub: `kleon1024/agi-playground`, public.
- File size ≤ 800 lines; folder density ≤ 8 files per directory.
- Commit format: `<type>(<scope>): <subject>`, imperative, ≤72 chars, no emoji. Forbidden verbs: change, update, modify, improve.
- Lesson/track docs must follow the design doc's lesson anatomy (`README.md` + `core/` + `prod/` + `runs/`) and the "read the toy, then map to the real thing" pedagogy.
- Never claim a run is verified without an actual `runs/` artifact. M0 ships zero verified runs; all track content is skeleton/outline marked `status: draft`.
- Source of truth documents every writer must read first: `docs/superpowers/specs/2026-07-24-agi-playground-design.md` and `research/synthesis.md`.
