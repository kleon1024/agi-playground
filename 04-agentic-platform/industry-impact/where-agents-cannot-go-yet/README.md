# The honest cells of the adoption matrix

> Dated survey, 2026-08-14.

**Question:** every adoption story implies the opposite question: where
cannot agents go yet? Naming the empty cells is what keeps the matrix
honest.

## The empty cells

**Unmeasurable outcomes** — creative direction, strategy, and taste: no
verifier can say "done", so no authorization matrix can be written.

**Catastrophic failure cost** — infrastructure that cannot fail, systems
where a wrong action is not recoverable: the gate would need to be so
strict that autonomy disappears.

**No audit trail** — domains where the surrounding system does not record
what happened: a governed agent cannot exist where the audit plane is
absent, because the no-suppressed-audit invariant has nothing to enforce.

**Low-trust data** — domains whose data is too dirty or adversarial for
retrieval and verification to be meaningful.

## Why naming them matters

The matrix's value is in the empty cells: they define what has to change
for an industry to enter it — measurability tooling, audit infrastructure,
or failure isolation. The mission's own honesty contract is the same
move: "never firing is not proof of safety" names what the evidence does
not cover.

## What this does not say

It does not claim these cells stay empty forever — every variable in the
matrix is improving. It claims the current boundary is real, and naming it
is the precondition for moving it.
