# The plan-as-contract generator, on the mission's real tasks

Rule-based planner (no model) turning the mission's private task records
into reviewable plan contracts.

## Command

```bash
cd 04-agentic-platform/intent-to-plan/a-minimal-planner/core
python3 planner.py --tasks ../../../tasks/private.jsonl
```

## Environment

| | |
|---|---|
| Machine | Apple silicon laptop, macOS arm64 |
| Python | 3.11 (system) |
| Model | none — rule-based, no API key |
| Cost | \$0 |

## Results

Two plans generated from `private.jsonl`:

| Task | Files to change | Tests | Verification |
|---|---|---|---|
| `private-b81c414` | `missions/01-language-model-agent/05-serve/core/engine.py` | `tests/test_decode_correctness.py` | `uv run --group torch pytest -q tests/test_decode_correctness.py` |
| `private-354c352` | `site/src/css/brand.css`, `site/sync-docs.py` | `tests/test_sync_docs.py` | `uv run pytest -q tests/test_sync_docs.py` |

Every field traces to the task record; the plan refuses to invent paths,
which is the contract property the stage claims.

## Honesty note

The planner is rule-based, so this run demonstrates the shape of a plan,
not the intelligence that fills one. No resolve-rate claim is made.
