# Rule verifier versus simulated judge, replayed over recorded verdicts

The mission's recorded tamper and idle verdicts run through two scorers: a
diff-reading rule verifier and a signal-reading simulated judge.

## Command

```bash
cd 04-agentic-platform/verification-and-evals/a-minimal-judge/core
python3 judge.py --out judge.json
```

## Environment

| | |
|---|---|
| Machine | Apple silicon laptop, macOS arm64 |
| Python | 3.11 (system) |
| Model | none — the judge is a deterministic rule over the recorded numbers |
| Cost | \$0 |
