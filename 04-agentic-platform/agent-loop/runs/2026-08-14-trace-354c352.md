**The change:**
The function now splits each line by backticks to identify inline code segments, then only escapes angle brackets (`<` → `&lt;`) in text outside backticks (even indices after split). Text inside backticks (odd indices) is left completely untouched.

**How it works:**
- Fenced code blocks (triple backticks) continue to be skipped entirely
- Inline code spans (single backticks) are now preserved verbatim
- Regular prose still gets `<` escaped to `&lt;` as before
