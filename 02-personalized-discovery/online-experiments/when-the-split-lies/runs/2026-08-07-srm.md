# Run — the SRM check beats the outcome test to the answer

**Date:** 2026-08-07
**Command:** `uv run python core/srm_detect.py`
**Hardware:** Apple M1 Pro, macOS 15.6.1, CPU-only.
**Software:** Python 3.12.9 via uv; stdlib only.
**Wall-clock:** under one second.
**Cost:** \$0 (local lane).

## Purpose

Measure how the allocation-ratio check behaves as traffic grows under a
bucketing bug (threshold 52 while the config declares 50/50), and compare
the traffic it needs against the outcome test's power requirement.

## Output

```
== 1. the bug: a one-constant drift in the bucket threshold ==
bucket(user_id): crc32 % 100 < threshold; config declares 50/50.

== 2. the find: the allocation-ratio check at increasing traffic ==
   users  treat%    chi2          p  sr check
     500  52.60%    1.35      0.245  silent
    1000  52.70%    2.92     0.0877  silent
    2000  52.75%    6.05     0.0139  FIRES
    2500  52.40%    5.76     0.0164  FIRES
    3000  52.50%    7.50    0.00617  FIRES
    4000  52.40%    9.22     0.0024  FIRES
    8000  51.96%   12.32   0.000447  FIRES
   16000  51.75%   19.60   9.55e-06  FIRES

sample ratio mismatch fires at 2000 users

== 3. why you cannot wait for the outcome ==
a 2% lift at 80% power needs 39,244 users per arm (78,489 total);
the split check fired at 2000 -- roughly 39x earlier

== 4. the fix: correct the constant, same users, same sessions ==
threshold 52: 51.96% treatment, chi2=12.32, p=0.000447 -> INVALID
threshold 50: 49.90% treatment, chi2=0.03, p=0.858 -> split restored
```

## Notes

- The user ids are hashed with crc32 so assignment is deterministic; a
  production bucketer must be deterministic the same way (Python's salted
  built-in hash would change buckets across processes).
- The observed treatment share is around 52% at every sample size, yet the
  check stays silent until roughly 2,000 users: SRM detection is a
  statistical test, not an eyeball on the ratio.
- The daily-check discipline comes from Fabijan, Gupta, Fetterman, and
  Hudson (2019), "Diagnosing Sample Ratio Mismatch in Online Controlled
  Experiments", KDD 2019.
