# Run — the shared bucket reports the other team's effect as yours

**Date:** 2026-08-08
**Command:** `uv run python core/overlap_sim.py`
**Hardware:** Apple M1 Pro, macOS 15.6.1, CPU-only.
**Software:** Python 3.12.9 via uv; stdlib only.
**Wall-clock:** under one second.
**Cost:** \$0 (local lane).

## Purpose

Measure what each of three platform designs reports when two experiments
share one traffic stream and one outcome, under a known truth: experiment
A moves the metric by 1.0, experiment B by 0.5, and the interaction is
0.5 — when both treatments are on, the metric moves by 2.0, not 1.5.
20,000 users, noise sd 2.0, deterministic crc32 hashing, seeded RNG.

## Output

```
== 1. the truth ==
20,000 users; A effect 1, B effect 0.5, interaction 0.5, noise sd 2
when both treatments are on, the metric moves by 2, not 1.5.

== 2. naive shared bucket: one flag, two experiments ==
assignment correlation: 1.00 (identical by construction)
experiment A reports 1.994 (se 0.028, p=0)
experiment B reports the same 1.994 - the two changes are
indistinguishable, and the estimate is A+B+interaction, not A.
the other team's effect is fully inside your number.

== 3. layered randomization: each experiment owns a layer ==
assignment correlation: 0.007 (independent layers)
experiment A reports 1.253 (se 0.029, p=0); truth is A + interaction/2 = 1.25
experiment B reports 0.746 (se 0.030, p=0); truth is B + interaction/2 = 0.75
each main effect is right, averaged over the other experiment's
50/50 rollout - and neither one sees the interaction.

== 4. the 2x2 factorial: the only design that sees the interaction ==
    cell    users     mean
(A=0,B=0)    5,088   99.977
(A=0,B=1)    4,914  100.498
(A=1,B=0)    5,014  101.011
(A=1,B=1)    4,984  101.964

A effect with B off:  1.035 (truth 1)
A effect with B on:   1.466 (truth 1.5)
B effect with A off:  0.521 (truth 0.5)
B effect with A on:   0.952 (truth 1)
interaction:          0.431 (truth 0.5)

== 5. the verdict ==
the shared bucket is confident and wrong: a tight p-value on an
estimate that is not your change. Layering gives every experiment
its own unbiased main effect at the cost of interaction blindness;
when two changes touch the same funnel, only the factorial reads
the interaction - Tang et al. 2010 (KDD) for the layered design,
Kohavi et al. 2009 (DMKD 18(1)) for the interaction trade.
```

## Notes

- The naive shared bucket has both experiments hash the same key and write
  to the same treatment flag, so assignment is identical for every user
  (correlation 1.00). Each experiment reports 1.994 — the sum of both
  effects plus the interaction — with a tight p-value, which is the
  dangerous case: a confident number that is not your change.
- Layered randomization keys each experiment to an independent layer
  (crc32 with a per-layer salt), so assignments are uncorrelated
  (correlation 0.007). Each estimate converges to the main effect averaged
  over the other experiment's 50/50 rollout: A reports 1.253 against
  A + interaction/2 = 1.25, B reports 0.746 against 0.75. Unbiased main
  effects, interaction invisible.
- Only the 2x2 factorial reads A at B-off (1.035 vs truth 1), A at B-on
  (1.466 vs 1.5), B at A-off (0.521 vs 0.5), B at A-on (0.952 vs 1), and
  the interaction (0.431 vs 0.5) separately — the interaction is read as
  the cell mean that cannot be expressed as the sum of the two main
  effects (1.0 + 0.5 + 0.5 = 2.0 observed, not 1.5).
- The layered design and the interaction trade are from Tang, Agarwal,
  O'Brien and Meyer (2010), "Overlapping experiment infrastructure: more,
  better, faster experimentation", KDD 2010, pp. 17-26; the factorial
  interaction detection is from Kohavi, Longbotham, Sommerfield and Henne
  (2009), "Controlled experiments on the web: survey and practical guide",
  Data Mining and Knowledge Discovery 18(1): 140-181.
