# Run — when pCTR moves the rank, executed on the stage's ads

**Date:** 2026-08-06
**Command:** `uv run python core/pctr_read.py`
**Hardware:** Apple M1 Pro, macOS 15.6.1, CPU-only.
**Software:** Python 3.11.14 via uv; stdlib only.
**Wall-clock:** 0.02s.
**Cost:** \$0 (local lane).

## Purpose

ECPM ranking turns on the pCTR estimate. This run sweeps one ad's pCTR
and shows the rank flip.

## Output

```
  Ad A pCTR  Ad A eCPM  Ad B eCPM  winner
       0.03      60.00     150.00      B
       0.05     100.00     150.00      B
       0.07     140.00     150.00      B
       0.09     180.00     150.00      A
       0.11     220.00     150.00      A
```

## Notes

- Ad B wins while Ad A's pCTR is below 0.075; above it Ad A's high bid
  takes over.
- The ranking is a knife-edge on the click estimate — which is why
  calibration (stage 16) is the precondition, not a polish step.
