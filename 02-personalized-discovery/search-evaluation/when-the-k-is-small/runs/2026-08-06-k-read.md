# Run — the k in NDCG@k, executed on one ranking

**Date:** 2026-08-06
**Command:** `uv run python core/k_read.py`
**Hardware:** Apple M1 Pro, macOS 15.6.1, CPU-only.
**Software:** Python 3.11.14 via uv; stdlib only.
**Wall-clock:** 0.02s.
**Cost:** \$0 (local lane).

## Purpose

NDCG@k is computed over the top k positions. This run shows how the
verdict changes with k on the same ranking.

## Output

```
  NDCG@1 = 0.000
  NDCG@3 = 0.500
  NDCG@5 = 0.546
```

## Notes

- At k=1 the top item is irrelevant (grade 0) so NDCG is 0; at k=3 the
  strong hits at 2-3 lift it.
- The verdict flips with k, so k must be declared with the metric.
