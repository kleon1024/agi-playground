## Purpose

Stage 02's recall index returns candidates. This run asks how much of the
candidate set the popular head occupies and what that does to tail
coverage.

## Output

```
  top 100 items hold 69.3% of all demand
  items 101-1000 hold 30.7%
  a 200-item recall pass keeps 100/900 tail items
```

## Notes

- Popularity concentrates: the top 10% of items carry 69.3% of demand.
- A recall index that learns from demand serves the head and starves the
  tail — tail coverage is a deliberate trade, not an accident.
